# 项目初始化
```shell
mkdir 项目名
cd 项目名
go mod init 项目名
```
此时会生成`go.mod`文件
go.sum 一般是在你下载依赖之后产生
之后再次添加依赖时就会生成`go.sum`文件
```shell

go mod download
```
| 命令              | 主要作用     | 修改 `go.mod` | 修改 `go.sum` | 删除无用依赖 |
| ----------------- | ------------ | ------------- | ------------- | ------------ |
| `go mod tidy`     | 整理项目依赖 | ✅ 可能        | ✅             | ✅            |
| `go mod download` | 下载模块     | ❌ 通常不改    | ✅ 可能        | ❌            |
| `go mod edit`     | 编辑 `go.mod` | ✅             | ❌            | ❌            |
| `go mod graph`    | 显示依赖树   | ❌            | ❌            | ❌            |
| `go mod vendor`   | 生成 vendor  | ✅             | ✅            | ❌            |
| `go mod verify`   | 验证依赖     | ❌            | ✅            | ❌            |
| `go mod why`      | 查询依赖     | ❌            | ❌            | ❌            |

# go get、go install区别
可以把 go get 和 go install 先简单记成：
- go get：给“项目”添加/升级依赖
- go install：给“电脑”安装一个 Go 命令工具
