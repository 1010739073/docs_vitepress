# 生成go.sum文件

```shell
go mod tidy

go mod download
```
| 命令              | 主要作用     | 修改 `go.mod` | 修改 `go.sum` | 删除无用依赖 |
| ----------------- | ------------ | ------------- | ------------- | ------------ |
| `go mod tidy`     | 整理项目依赖 | ✅ 可能        | ✅             | ✅            |
| `go mod download` | 下载模块     | ❌ 通常不改    | ✅ 可能        | ❌            |


# 生成go.mod文件
```shell
go mod init 项目名
```
