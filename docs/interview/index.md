# 面试题

后端面试题库，覆盖 Go、Node.js、AI、PHP、MySQL、Python、Redis 七个方向，并包含**滴滴专项**（按语言拆分的真题补充 + 出行业务场景题 + 必写算法清单）。

## 两份文档怎么配合

| 文档 | 定位 | 什么时候看 |
| --- | --- | --- |
| [答案版](./1.面试题库-答案版) | **唯一答案库**，19 章 233 题 | 平时学习、写不出来的题回来查 |
| [口述精简版](./2.面试题库-口述精简版) | **速记索引**，一题一行 | 面试前 10 分钟、通勤路上 |

答案版**全部 233 题统一四段式**（Go / Node / AI / 简历深挖 / 滴滴专项 / PHP / MySQL / Python / Redis 一致）：

1. **① 专业表述** —— 面试原话，上场就说这段；
2. **② 白话理解** —— 自己看，把原理想通，不上场说；
3. **③ 流程 / 机制** —— 按步骤讲清底层；
4. **④ 追问防身** —— 面试官接着问什么，怎么接。

## 推荐复习路线

::: tip 面试滴滴（Go 后端）
1. **第十四章** 必写算法 12 道 —— 写不出来其他都白搭；
2. **第十三章** 出行业务场景 7 题 —— 决定二面过不过；
3. **第八～十二章** 八股 —— 一面保底；
4. 进场前扫一遍**精简版第十二节**速记卡。
:::

::: tip 面试 PHP / MySQL / Redis 岗
第十六～十八章为主，配合精简版对应章节自测；MySQL 的 MVCC 与锁、PHP 的安全与生命周期是重点被追问处。
Redis 单独看**第十九章**（26 题通用体系题）+ **第十章**（8 题滴滴真题），两边互补不重复。
:::

::: warning 关于第四章「简历深挖题」
答案给的是**答题框架 + 技术内核**，括号里的数字必须换成自己的真实经历。编数字一旦被追问细节就会露馅。
:::

## 使用建议

- **第一遍只读 ②**：当科普看，20 分钟通读一章，先把道理弄懂；
- **第二遍读 ①**：对着术语确认自己能说出口，术语说不顺就回去看 ②；
- **第三遍只看 ④ 和「记忆锚点」**：查漏补缺，练追问；
- **自测**：翻到答案版文末附录，只看题目清单，逐条自问「这题我说得出 ① 吗」。
